Projeto de Análise Exploratória de Dados (EDA) - COVID-19
Este projeto de análise exploratória de dados (EDA) examina os dados globais de COVID-19 para explorar as tendências e métricas relacionadas à pandemia. Através da manipulação e visualização dos dados, o objetivo é obter uma visão geral do impacto da pandemia, como a distribuição de casos confirmados, mortes, recuperações, taxas de mortalidade e mais.

Conteúdo do Repositório
O repositório contém um conjunto de dados sobre COVID-19 com informações de países e estados, incluindo os seguintes campos:

Country/Region: País ou região.
Province/State: Província ou estado (se disponível).
ObservationDate: Data de observação.
Last Update: Última atualização dos dados.
Confirmed: Casos confirmados.
Deaths: Mortes confirmadas.
Recovered: Recuperações.
Continent: Continente (adicionado durante o processamento).
Além disso, o repositório contém um código em Python que realiza a análise exploratória dos dados, visualizações interativas e gráficos informativos, como:

Evolução dos casos de COVID-19 ao longo do tempo.
Comparação entre países com mais casos confirmados.
Taxa de mortalidade por país.
Casos ativos por país.
Análise por continente.
Objetivos
Explorar os dados relacionados ao COVID-19, incluindo casos confirmados, mortes e recuperações.
Visualizar a evolução temporal do número de casos.
Comparar países com mais casos confirmados, mortes e taxas de mortalidade.
Avaliar a distribuição de casos por continente.
Calcular a taxa global de mortalidade.
Requisitos
Para rodar este projeto localmente, você precisará das seguintes bibliotecas Python:

pandas
numpy
plotly
matplotlib
seaborn

O código irá gerar gráficos e tabelas interativas para análise, incluindo a evolução global da pandemia e a taxa de mortalidade por país.

O projeto gera diversos gráficos interessantes, incluindo:

1. Evolução do número total de casos confirmados e mortes ao longo do tempo

2. Top 10 países com mais casos confirmados

3. Top 10 países com maior taxa de mortalidade

4. Casos ativos por país

5. Distribuição por Continente

Conclusão
Este projeto de análise exploratória proporciona insights valiosos sobre a distribuição e o impacto da pandemia de COVID-19 em diferentes países e continentes. O código é extensível, permitindo que você adicione mais visualizações ou métricas de seu interesse.
